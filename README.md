# 🛸 Rick & Morty Universe

App React que consume la Rick and Morty API pública.

## 📌 Tecnologías
- React 19 + Vite
- React Router DOM
- Tailwind CSS v3

## 🚀 Ejecutar

```bash
git clone https://github.com/pabloislaarone/evaluaci-n03.git
cd rickmorty-react
npm install
npm run dev
```

🌐 Deploy: https://evaluaci-n03.vercel.app/
